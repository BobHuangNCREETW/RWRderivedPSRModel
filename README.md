# RWRderivedPSRModel
This study presents a new empirical model for the probability of surface rupture (PSR) for crustal earthquakes, a key component of probabilistic fault-displacement hazard analyses. The PSR model is developed from a dataset compiled from a literature review of rupture parameters from earthquakes that occurred between 1970 to 2023. The new aspect of the proposed PSR model is the use the rupture-width ratio (RWR) as the main source parameter rather than moment magnitude used in current PSR models. The RWR is defined as the ratio of the rupture width to the down-dip fault width. In addition to the RWR, a normalized average depth parameter, defined as the average focal depth divided by the depth of the bottom of the fault, is included as a source parameter to account for regional differences in the depth distributions. Other physical parameters, such as style-of-faulting, shear-wave velocity at seismogenic depths, and rupture aspect ratio, were evaluated but not modeled due to large epistemic uncertainty in the estimated scaling. Using the RWR provides physical constraints that do not apply to magnitude. If the RWR is unity, then PSR is also unity. To account for this constraint, the shape of the PSR model is modeled by a Beta cumulative distribution function (CDF) rather than the common approach of assuming the shape from a logistic regression. Source scaling models for the magnitude dependence of the rupture dimensions can be used to convert the RWR-based PSR to a magnitude-based PSR while accounting for the effect of fault-specific fault width. By accounting for the fault-specific fault width, the resulting RWR-based model for the PSR provides more accurate fault-specific estimates of the PSR than global magnitude-based PSR models. 

The new RWR-derived PSR model is provided in [sub_RWR_derived_PSRmodel.m], with an example main program in [main_prediction.m]. The regression code for an example table is provided in [sub_fitBetaMLE_fixbeta.m] for the stage 1 (S1) model, with an example main program in [main_regression.m].

Example codes for applying the example procedure are shown in the folder [fault_based_SSM_PSR_application]. These codes demonstrate how to apply Huang et al.'s (SRL, 2024) updated source scaling models by translating them from the regional scale to fault-based methods, as detailed in the Appendix of Huang and Abrahamson (2026). These implementations are shown in the plots in Fig. 12(a) and Fig. A2(b), with a combined method using the RWR-based PSR model. The main example program is in [main_fault_based_Hea24_w_RWR_PSR.m], with a fundamental fault-based Hea24 SSM provided in [sub_fault_based_Hea24.m] and [sub_makeComparecurve.m], and other related scripts include [sub_pt_AV_range.m], [sub_pt_progress_comp_threecurves.m], [sub_pt_RWRPSR_w_other_models.m], and [sub_RWR_derived_PSRmodel.m]. The [sub_Mea25.m] is sourced from Mea25 (Mammarella et al. EQS (2025), doi: 10.1177/87552930241293570), which was downloaded from https://github.com/MammarellaLisa/CPSR (last accessed May 2025).
